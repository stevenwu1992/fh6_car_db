## 1. 转速单位：rad/s → rpm

### 1.1 变更前

车辆详情页「动力总成与结构」分区里，三个转速字段直接显示数据库原始值（弧度/秒），普通用户需要自己乘 9.5493 才能理解。

| 字段 | 变更前 |
|---|---|
| 峰值功率转速 | `1005.3 rad/s` |
| 峰值扭矩转速 | `733 rad/s` |
| 断油转速 | `1068.1 rad/s` |

### 1.2 变更后

| 字段 | 变更后 |
|---|---|
| 峰值功率转速 | `9600 rpm` |
| 峰值扭矩转速 | `7000 rpm` |
| 断油转速 | `10200 rpm` |

### 1.3 换算规则

```
rpm = rad/s × 60 / (2π) = rad/s × 9.549296585513721
```

换算后四舍五入取整。原始数据本身是按整数 rpm 生成再折算成 rad/s 保存的，因此取整能无损还原游戏内真实数值——这不是近似，是反算。

### 1.4 覆盖范围

| 字段 | 原单位 | 新单位 | 新取值范围 |
|---|---|---|---|
| `SimPeakAngVel` 峰值功率转速 | rad/s | rpm | 2000 ~ 15900 |
| `SimPeakTorqueAngVel` 峰值扭矩转速 | rad/s | rpm | 0 ~ 10200 |
| `SimRedlineAngVel` 断油转速 | rad/s | rpm | 2500 ~ 21000 |

字段说明（glossary）同步改写，不再出现「换算：rpm = rad/s × 9.5493」这类让用户自己算的表述。

### 1.5 准确性验证

对构建产物做了全量比对，而不是抽样：

| 项 | 结果 |
|---|---|
| 核对范围 | 691 台车 × 3 字段 = **2073 个数值** |
| 比对方式 | 直接从 SQLite 原始 rad/s 重算，与页面 payload 逐项对照 |
| 不一致数量 | **0** |
| 越界检查 | 页面实际取值范围与字典声明完全一致 |

## 2. 后台登录：新增密码 + 防护

### 2.1 变更前的问题

`admin.html` 是公开可访问的静态页（还被首页导航直接链接）。原来唯一的门槛是 `ADMIN_EMAILS` 邮箱白名单——必须先走邮箱 Magic Link 登录，且服务端未配置邮件通道时这条路根本走不通。

结果是：**页面人人可打开，权限又拿不到**，同时缺少针对登录的爆破防护。

### 2.2 变更后

页面打开先请求 `/api/me`，非管理员只显示一个密码框，表格完全不渲染。密码通过后拿到独立的 `fh6_admin` 会话 cookie，才加载数据。

### 2.3 新增接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/auth/admin/session` | 查询当前是否已登录（200 / 401） |
| `POST` | `/auth/admin/login` | 提交 `{ password }`，成功签发会话 |
| `POST` | `/auth/admin/logout` | 销毁会话并清 cookie |

### 2.4 防护设计

| 层 | 做法 | 目的 |
|---|---|---|
| 密码比对 | 两侧先 sha256 再 `timingSafeEqual` | 定长常量时间比较，不泄露长度与内容 |
| 会话载体 | 独立 cookie `fh6_admin`，`HttpOnly` + `SameSite=Strict` | 与玩家会话隔离，JS 读不到 |
| 会话时效 | 默认 12 小时（`ADMIN_TTL_HOURS` 可调 1–72） | 泄露窗口可控 |
| 暴力破解 | 单 IP 5 次失败锁 15 分钟；全局 100 次/小时；成功即清零 | 单点与分布式都挡 |
| 提权范围 | 只写 `admin_sessions` 表，**不写 `users.is_admin`** | 不会给玩家账号留永久管理员身份 |
| 审计 | 成功/失败均写 `audit_log`，只存 IP 哈希 | 事后可追溯，不留隐私 |
| 写接口 | `/api/tiers/:carId` 校验管理员；仍要求 Origin 白名单 + `X-CSRF` + JSON | 纵深防御 |
| 存储 | 会话只存 token 的 sha256 | 数据库泄露无法直接冒用 |

### 2.5 实测记录

| 场景 | 结果 |
|---|---|
| 未登录查询会话 | `401` |
| 错误密码 | `401 BAD_PASSWORD` |
| 正确密码 | `200` + `Set-Cookie: fh6_admin=…`（HttpOnly） |
| 纯密码会话（无玩家 cookie）写入分级 | `200` ✓ |
| 无任何凭据写入分级 | `401 NO_SESSION` |
| 连续输错 5 次后第 6 次 | `429 RATE_LIMITED` |
| 登出后复用旧 cookie | `401` |

### 2.6 配置要求（部署必看）

```bash
# 生成一个够强的密码
node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"

# 写入环境
ADMIN_PASSWORD=<生成值>
ADMIN_TTL_HOURS=12        # 可选
```

未配置时，`/auth/admin/login` 返回 `503 NOT_CONFIGURED`，启动日志会打印告警。**这是刻意的失败关断，不是 bug。**

## 3. 部署配置：缓存头与迁移文档

### 3.1 新增 `_headers`

按资源类型分层，**没有**对图片使用 `immutable`——因为图片文件名是车辆 ID，不含内容哈希，一旦重导出同图，老访客一年都刷不出新图。

| 路径 | Cache-Control | 折算 |
|---|---|---|
| `/*` | `public, max-age=600, must-revalidate` | 10 分钟 |
| `/output/assets/*` | `public, max-age=2592000, stale-while-revalidate=604800` | 30 天 + 7 天静默续期 |
| `/output/assets/fonts/*` | `public, max-age=31536000, immutable` | 1 年 |
| `/output/admin.html` | `no-store` | 不缓存 |

同时附带 `X-Content-Type-Options`、`X-Frame-Options: SAMEORIGIN`、`Referrer-Policy`、HSTS 180 天，以及预览域与后台页的 `X-Robots-Tag: noindex`。

### 3.2 更新生效时间

| 改了什么 | 老访客多久看到新版 |
|---|---|
| 车表数据 / 任意 HTML | 10 分钟内 |
| 车辆图片（文件名不变） | 最长 30 天 |
| 字体 | 不刷新（字体本身不再变） |
| `admin.html` | 立即 |

需要改图立即生效，只能改文件名或加 `?v=<时间戳>`——控制台 purge 只能救新访客，清不掉浏览器里已缓存的旧图。

### 3.3 新增文档

`docs/cloudflare-pages-migration.md`：GitHub Pages → Cloudflare Pages 的完整落地记录，含构建参数、Cache Rules 顺序、验证清单、回滚步骤。

## 6. 回滚

```bash
git revert 7481aa9
git push origin main
```

注意两点：

1. `admin_sessions` 表不会被删除（`CREATE TABLE IF NOT EXISTS` 无反向操作），但残留空表无害；
2. 回滚后后台回到「仅邮箱白名单」模式，若未配置邮件通道，后台将无法登录。

只回滚转速、保留后台加固：

```bash
git checkout 7481aa9^ -- build_web.py dictionary.py output/
git commit -m "revert: 转速单位回退为 rad/s"
```
